Cấu hình phiên

Ghi chú

Giá trị trong .env (TIKTOK_USERNAME / WS_TOKEN / DEMO_MODE) được ưu tiên lúc khởi động. Thay đổi ở đây áp dụng ngay và lưu vào config.json; bỏ biến trong .env để dùng giá trị đã lưu.

Hướng dẫn & API

Hướng dẫn sử dụng

  1. Mở trang /admin, đăng nhập bằng ADMIN_TOKEN (trong .env; nếu để trống thì xem dòng ADMIN_TOKEN: ở log lúc khởi động server).
  2. Kiểm tra trạng thái trên thanh trên cùng: Live/Demo, Đã kết nối TikTok hay chưa, room id, người xem, thời gian chạy.
  3. Vào tab Cấu hình: đặt username TikTok đang live, đặt WS_TOKEN nếu muốn bảo vệ cổng WebSocket, bật Chế độ demo để test không cần TikTok. Nhấn Lưu & áp dụng.
  4. Tab Feed để theo dõi sự kiện realtime; Thống kê để xem tổng quan; Client để quản lý kết nối từ game.
  5. Game của bạn kết nối vào WebSocket (phần dưới) để nhận data — không cần đăng nhập admin.

Ghi chú từng chức năng

  • Feed — hiển thị 300 sự kiện gần nhất trong trình duyệt; lọc theo loại, tạm dừng, xóa.
  • Thống kê — cập nhật mỗi 2s; nút Reset xóa số liệu phiên.
  • Client — liệt kê kết nối WebSocket (game + admin), có thể ngắt từng client. Tự làm mới mỗi 5s.
  • Cấu hình — đổi username/WS_TOKEN/demo mode, áp dụng ngay, lưu vào config.json. Nút Kết nối lại TikTok dùng khi kết nối bị rớt.
  • Toàn bộ /api/admin/* và WebSocket admin /admin yêu cầu phiên đăng nhập (cookie 12 giờ).

Kết nối từ game (WebSocket)

Địa chỉ WebSocket của phiên này:

// Ví dụ kết nối từ game (JavaScript)
const ws = new WebSocket(WS_URL); // thay WS_URL bằng link ở trên

ws.onopen = () => console.log("Đã kết nối!");
ws.onmessage = (e) => {
  const msg = JSON.parse(e.data);      // { type: "tiktok", payload: { type, data } }
  const ev = msg.payload;
  switch (ev.type) {
    case "comment": console.log(ev.data.user.nickname, ":", ev.data.content);
    case "gift":    console.log(ev.data.giftName, "x" + ev.data.repeatCount, ev.data.diamondCount + " diam");
    case "like":    console.log("+" + ev.data.count, "tim"); // user có thể là null
    case "follow": case "share": case "member": console.log(ev.data.user.nickname, ev.type);
    case "viewer":  console.log("viewers:", ev.data.viewerCount);
    case "status":  console.log("connected:", ev.data.connected, ev.data.roomId);
  }
};

Ngay khi client vừa kết nối, server gửi 1 event status (connected, username, roomId) để game biết trạng thái hiện tại. Nếu WS_TOKEN sai → server đóng kết nối mã 1008.

Cấu trúc payload

Mọi sự kiện gửi tới game đều có dạng { "type": "tiktok", "payload": { "type": "…", "data": {…} } }.

LoạiNội dung data
comment{ user, content, timestamp }
gift{ user, giftId, giftName, diamondCount, repeatCount, imageUrl, timestamp }
like{ user|null, count, total, timestamp } — TikTok gộp like nên user có thể null
follow{ user, timestamp }
share{ user, timestamp }
member{ user, memberCount, timestamp }
viewer{ viewerCount, timestamp }
status{ connected, username, roomId?, demoMode? }

user = { uniqueId, nickname, avatarUrl }. Tap tim 1 lần và double-tap đều cùng loại event, chỉ khác count.

Ghi chú chung

  • 1 instance = 1 thuê bao = 1 phiên live. Muốn nhiều thuê bao thì chạy nhiều container với port + token riêng.
  • Cần username TikTok đang live mới kết nối được; offline → tự retry (backoff tối đa 30s).
  • Nhiều kết nối từ cùng 1 IP dễ bị TikTok rate limit (backoff 60s → 5 phút). Nên phân tán server/IP và dùng SIGN_API_KEY (Euler Stream) nếu cần.
  • ENABLE_EXTENDED_GIFT_INFO mặc định false — bật cần gói Business của Euler Stream (trả phí).
  • Env trong .env ưu tiên hơn config.json lúc khởi động; muốn dùng giá trị đã lưu thì bỏ biến tương ứng.
  • Nếu để trống ADMIN_TOKEN, token tự sinh sẽ đổi mỗi lần restart server — nên đặt mật khẩu cố định trong .env.
